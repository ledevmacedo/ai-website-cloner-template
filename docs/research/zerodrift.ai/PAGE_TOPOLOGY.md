# ZeroDrift Page Topology

Target URL: `https://www.zerodrift.ai`

## Flow
1. Header navigation, fixed-height normal flow, desktop menu plus mobile hamburger.
2. Hero panel, orange video background, backing label, H1, demo buttons, compliance seals, embedded showreel thumbnail.
3. Trusted logo strip, centered mono label and horizontal cards.
4. Real-Time Enforcement Layer, white grid panel with Compose/Guard/Command tabs and three alternating feature rows.
5. What Fast and Compliant Looks Like, three-card proof section.
6. See It Work, centered video placeholder panel with pause button.
7. Channel grid, workflow/team/industry pills and channel cards.
8. API infrastructure, copy plus request/response code panels.
9. Engineered trust section, centered long white grid panel.
10. Demo CTA, blue/pink motion background, email input, quote card.
11. Footer, logo, address, nav columns, contact rows, copyright.

## Responsive Behavior
- Desktop `1440px`: navigation links visible, hero is large two-column bottom layout, feature rows alternate text/image.
- Tablet `768px`: sections keep card widths but reduce gutters.
- Mobile `390px`: header collapses to logo plus menu icon, hero and all content stacks in one column, logo strip scrolls horizontally.

## Interaction Models
- Header links and buttons: hover color/background changes.
- Hero video and CTA background: time-driven looping media.
- Showreel and See It Work: play/pause visual affordances, no real modal backend in clone.
- Channel pills: visual segmented controls only, matching visible default state.
